# 🏢 Tiny Office

**Claude Code 직원들이 일하는 작은 픽셀 사무실.**
터미널의 `claude` CLI를 감싼 macOS 앱이에요. 직원 한 명이 Claude 세션 하나이고, 사무실 화면에서 귀여운 캐릭터로 일하는 모습을 볼 수 있어요.

## 다운로드

[**Releases**](../../releases/latest)에서 최신 `TinyOffice-x.y.z.dmg`를 받으세요.

1. dmg를 열고 `Tiny Office`를 **응용 프로그램** 폴더로 드래그해요.
2. 실행하면 대표 이름을 정하는 첫 설정 화면이 나와요.
3. 새 버전이 나오면 앱 상단에 알림 배너가 떠요. **다운로드**를 눌러 새 dmg로 교체하면 돼요.

Apple 공증(notarization)을 받은 앱이라 그냥 열 수 있어요.

## 준비물

- **macOS 26 이상**
- **Claude Code CLI** 설치와 로그인 (`claude` 명령이 터미널에서 실행돼야 해요)
  - 설치: <https://docs.claude.com/en/docs/claude-code/overview>
  - 앱이 자동으로 `claude` 위치를 찾아요. 못 찾으면 설정에서 경로를 직접 골라 주세요.
  - 너무 오래된 버전이면 앱 상단에 업데이트 안내가 떠요. 터미널에서 `claude update`를 실행하세요.
  - 로그인이 안 되어 있으면 앱 상단의 **로그인** 버튼으로 연결할 수 있어요.

## 사용법

### 시작하기
1. 왼쪽 레일의 **＋** 버튼으로 작업할 **프로젝트 폴더**를 추가해요. 폴더 하나가 프로젝트 하나예요.
2. 프로젝트에는 기본으로 PM과 개발자 직원이 있어요. 직원 목록이나 사무실의 캐릭터를 눌러 오른쪽 채팅창에서 일을 시키세요.
3. 직원 목록의 **👤＋** 버튼으로 직원을 더 추가하고, 직책과 역할(시스템 프롬프트)을 정할 수 있어요.

### 화면 구성
| 탭 | 설명 |
| --- | --- |
| 사무실 | 직원들이 책상에서 일하고, 쉴 때는 소파에서 쉬어요. 질문이나 승인이 필요하면 말풍선이 떠요. |
| 조직도 | 대표, PM, 팀원 구성을 한눈에 봐요. |
| 직원표 | 직원별 상태와 하는 일을 표로 봐요. |

채팅창에는 **채팅 / 작업 / 변경 파일 / 검색** 탭이 있어요.

### 권한 모드
직원마다 정할 수 있어요.

- **자동 (터미널 auto 모드)**: 안전한 작업은 자동 허용하고, 위험한 건 물어봐요.
- **CLI 설정 따름**: 모드를 강제하지 않고 CLI와 프로젝트 설정을 그대로 따라요.
- **편집은 자동 허용**: 파일 수정은 자동 허용, 명령 실행은 물어봐요.
- **모두 허용 (확인 없음)**: 확인 없이 전부 실행해요. 신뢰하는 폴더에서만 쓰세요.

도구 사용 허가를 물어볼 때는 채팅창에 허용 / 거절 카드가 떠요.

### 주요 기능
- **질문 카드**: Claude가 선택지를 물어보면 카드로 떠요. 고르거나 직접 입력해서 답해요.
- **계획 승인 카드**: 계획 모드에서 계획을 보여주면 승인 / 거절할 수 있어요.
- **PM 팀 배정**: PM 직원은 일을 나눠서 팀원들에게 배정할 수 있어요.
- **파일 미리보기**: 답변에 나온 이미지는 썸네일로, PDF·CSV·엑셀·Word·PowerPoint·ZIP·HTML은 칩으로 보여주고 눌러서 열어요.
- **소스 파일 칩**: `파일명.swift:123` 같은 경로를 누르면 Xcode의 해당 줄로 이동해요.
- **이전 대화 불러오기**: Claude Code CLI의 세션을 제목, 브랜치, 크기와 함께 목록으로 보고 이어서 대화할 수 있어요.
- **직원 복제 / 팀 템플릿**: 직원을 우클릭해서 복제하거나, 팀 구성을 템플릿으로 저장해 다른 프로젝트에서 불러와요.
- **대화 내보내기**: 대화를 Markdown(.md) 파일로 저장해요.
- **슬래시 명령어와 파일 첨부**: 채팅창에서 `/`로 명령어를 쓰고, 파일을 첨부할 수 있어요.
- **알림**: 일이 끝나거나 확인이 필요하면 macOS 알림이 와요.
- **사용량 표시**: Claude 사용량 한도를 확인할 수 있어요.

### 설정
왼쪽 레일 아래 톱니바퀴(⚙︎)에서 해요.

- 대표 이름과 아바타 변경
- `claude` 경로 지정과 확인
- 저장 공간 확인과 오래된 첨부파일 정리
- 앱 버전 확인과 업데이트 확인
- 정보 초기화 (모든 프로젝트, 직원, 설정을 지워요)

## 데이터 위치

- 앱 상태: `~/Library/Application Support/TinyOffice/` (직원, 프로젝트, 첨부파일)
- 대화 기록: Claude Code가 저장하는 `~/.claude/projects/` 안의 세션 파일

모든 작업은 내 컴퓨터의 `claude` CLI로 실행돼요. 앱이 대화 내용을 따로 서버로 보내지 않아요.

## 문제 해결

| 증상 | 해결 |
| --- | --- |
| "claude를 찾을 수 없어요" | 설정에서 `claude` 경로를 직접 선택하거나, 터미널에서 `which claude`로 경로를 확인해 넣어 주세요. |
| "이 경로에서 claude를 실행할 수 없어요" | Claude Code를 최신으로 업데이트해 보세요 (`claude update`). 예전에 npm으로 설치한 `claude`가 남아 있으면 `npm -g uninstall @anthropic-ai/claude-code`로 지우세요. |
| 로그인 배너가 떠요 | 배너의 로그인 버튼을 누르면 브라우저에서 로그인해요. |
| 새 버전 알림이 안 떠요 | 설정의 **업데이트 확인**을 눌러 보세요. |
| 처음부터 다시 시작하고 싶어요 | 설정 → **정보 초기화** |
